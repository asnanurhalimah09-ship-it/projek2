# Personal Website - Asna Nur Halimah

Website pribadi sederhana yang dibuat menggunakan HTML dasar tanpa CSS maupun JavaScript. Proyek ini merupakan latihan pengembangan web untuk menampilkan biodata, profil, daftar project, dan halaman kontak.

## Deskripsi

Website ini berisi informasi mengenai diri saya sebagai mahasiswa Program Studi Pendidikan Sistem dan Teknologi Informasi (PSTI), Universitas Pendidikan Indonesia (UPI) Kampus Purwakarta. Melalui website ini, pengunjung dapat mengenal profil saya, melihat beberapa project yang pernah dikerjakan, serta menghubungi saya melalui form pesan yang tersedia.

## Struktur Halaman

| Halaman | File | Deskripsi |
|---|---|---|
| Home | `Home.html` | Halaman utama berisi sambutan, perkenalan singkat, dan daftar hal yang sedang dipelajari |
| About | `About.html` | Profil singkat, data diri, hobi, dan riwayat pendidikan |
| Project | `Project.html` | Daftar project yang pernah dikerjakan beserta ringkasan portofolio |
| Contact | `Contact.html` | Informasi kontak dan form pesan |

## Fitur

- Navigasi antar halaman (Home, About, Project, Contact)
- Tabel data diri dan ringkasan project menggunakan elemen `<table>`
- Form kontak dengan berbagai jenis input (text, email, tel, radio, date, select, textarea, checkbox)
- Penyisipan gambar menggunakan elemen `<img>`

## Teknologi yang Digunakan

- HTML5

## Catatan

Website ini hanya menggunakan HTML murni, sehingga:
- Belum menggunakan CSS untuk styling tampilan
- Form pada halaman Contact belum terhubung ke server atau database
